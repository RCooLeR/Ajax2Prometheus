# AjaxBridge

AjaxBridge receives Ajax security hub SIA DC-09 events, keeps the current alarm state in memory, exposes Prometheus metrics, and can publish Home Assistant MQTT discovery plus retained state.

## Repository layout

- [`bridge/`](./bridge/README.md): Go service, Docker files, compose file, runtime data examples, and MQTT/Home Assistant docs
- [`ha-cards/`](./ha-cards/README.md): Home Assistant Lovelace custom cards, standalone preview, assets, and example card configs

## What ships

- Prometheus exporter with `/metrics`, `/state`, `/events`, and `/devices`
- Optional MQTT discovery for Ajax devices in Home Assistant
- Lovelace cards that render live Home Assistant areas, devices, events, and room images

## Release artifacts

GitHub releases currently publish:

- the Go source archive generated by GoReleaser
- `ha-cards-dist.tar.gz` with the built Lovelace UI
